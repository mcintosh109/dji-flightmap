        Putting the file on the RC 2 by hand
        1. In DJI Fly, make (or keep) a placeholder waypoint mission. Note its date and number of waypoints in DJI Fly's list.
        2. Plug the RC 2 into your PC. In File Explorer open DJI RC 2 → Internal shared storage → Android → data → dji.go.v5 → files → waypoint, then the placeholder's folder (the long name).
        3. Copy the .kmz that is already there to your PC first, as a backup.
        4. Rename the downloaded file to exactly the same name as that .kmz, then copy it into the folder and choose Replace.
        5. Unplug, open DJI Fly, open the placeholder mission, and check the route on its map: the points, the heights (H), the speed, and the end and signal-lost actions. The small picture in DJI Fly's list may still show the old route; that's normal.

        1. Open the Proxmox web page, click your server name on the left, then >_ Shell.

        3. Wait until it says "Update finished".
